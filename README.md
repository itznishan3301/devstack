# Dev Stack Builder

Dev Stack Builder is a React application that helps developers visualize and select their ideal technology stack from a curated list of modern frameworks, libraries, and tools.

## Features
- **Responsive Layout:** Beautiful UI built with Tailwind CSS.
- **Data Fetching:** Loads a curated list of technologies from a local JSON dataset.
- **Stack Selection:** Add or remove technologies from your customized tech stack.
- **Toast Notifications:** Real-time feedback when modifying your stack.

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- DaisyUI
- React Toastify

## Running the Application
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
